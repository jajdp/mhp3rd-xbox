# The package tiles

*(Español: [ASSETS.es.md](ASSETS.es.md))*

The manifest names five images, and **this repository ships none of them**: the ones in the real
package were made from the game's own artwork. You supply your own.

| File | Size |
|---|---|
| `StoreLogo.png` | 50 × 50 |
| `Square150x150Logo.png` | 150 × 150 |
| `Square44x44Logo.png` | 44 × 44 |
| `Wide310x150Logo.png` | 310 × 150 |
| `SplashScreen.png` | 620 × 300 |

`tools/mosaicos.py` generates them from a source image of your own. PNG, 32-bit with alpha.

Keep whatever art you make yours: artwork from the game belongs to its owners, and a package that
carries it is a package you cannot share.
