# Los mosaicos del paquete

*(English: [ASSETS.md](ASSETS.md))*

El manifiesto nombra cinco imágenes, y **este repositorio no trae ninguna**: las del paquete real se
hicieron con el propio material artístico del juego. Las pones tú.

| Archivo | Medida |
|---|---|
| `StoreLogo.png` | 50 × 50 |
| `Square150x150Logo.png` | 150 × 150 |
| `Square44x44Logo.png` | 44 × 44 |
| `Wide310x150Logo.png` | 310 × 150 |
| `SplashScreen.png` | 620 × 300 |

`tools/mosaicos.py` las genera a partir de una imagen tuya. PNG de 32 bits con alfa.

Que el arte que hagas sea tuyo: el material del juego es de sus dueños, y un paquete que lo lleve es
un paquete que no puedes compartir.
